A way to the GitHub keys. GitHub opens the GitHub page on the deck it's on. Go to + opens it on the Stream Deck +, with the Branch Map on the dials.
  • The first time, Stream Deck asks to install the plugin's GitHub profile. Say yes once and it won't ask again
  • Every key on the page follows the Repo key, so the page opens on whatever repo is picked
  • The Home key on the GitHub page goes back to my Home profile
  • Profile: a whole layout of keys and dials for one deck. Switching profiles swaps every key at once
  • Bundled profile: a profile that comes inside a plugin. Plugins can only open their own
Switches the deck to the GitHub profile. If there's no + plugged in, Go to + shows a warning sign instead.
